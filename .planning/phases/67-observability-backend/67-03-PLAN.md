| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-67-03-compaction | Information Disclosure (false data) | compaction_triggers always 0 might mislead operators | mitigate | Inline comment cites RESEARCH A1: "Mem0 Platform server-side compaction is not client-observable; revisit v14 if self-hosted mem0." Honest zero rather than fabricated metric. |
