    ```python
    @app.get("/orchestrator/agents/status")
    def get_orchestrator_agents_status(request: Request):
        """Phase 67 OBSRV-01/02/03: operator observability endpoint.

        Read-only snapshot of agent registry health + round table metrics +
        memory backend metrics. Computed on-demand from in-memory ring buffers.
        """
        _require_token(request)  # RESEARCH Pitfall 5 — do NOT add to PUBLIC_API_PATHS

        # RESEARCH Pitfall 6: lazy imports avoid circular-import risk
        from agent.observability import (
            get_agent_registry_metrics,
            get_round_table_metrics,
            get_memory_backend_metrics,
        )
        from agent.registry_loader import load_agent_registry_with_warnings
        from agent.round_table_state import _now_iso as _state_now_iso

        # OBSRV-01: live registry snapshot (loader caches internally)
        try:
            entries, missing = load_agent_registry_with_warnings()
            schema_ok = True
        except Exception as exc:
            logger.warning("orchestrator status: registry load failed: %s", exc)
            entries, missing, schema_ok = [], [], False

        return {
            "agent_registry": get_agent_registry_metrics(entries, missing, schema_ok),
            "round_table": get_round_table_metrics(),
            "memory_backend": get_memory_backend_metrics(),
            "snapshot_at": _state_now_iso(),
        }
    ```

    **CRITICAL choices (cite RESEARCH pitfalls in inline comments):**
    1. Plain `def` (NOT `async def`) — RESEARCH Pitfall 4. FastAPI runs sync handlers in a threadpool; the handler does ~3 file reads + 3 buffer snapshots + percentile math (sub-millisecond). Avoids blocking the event loop.
    2. `_require_token(request)` as the FIRST line inside the handler — RESEARCH Pitfall 5. The auth gate covers both loopback-token mode and OAuth-cookie mode.
    3. Lazy imports INSIDE the handler body — RESEARCH Pitfall 6. Matches the existing pattern at `web_server.py:1797` (`from hermes_state import SessionDB` inside a handler).
    4. Catch `Exception` around the registry loader — V7 error handling. Never crash the endpoint; degrade to `schema_validation_ok=False`. Use lazy %-formatting: `logger.warning("...: %s", exc)`.
    5. Return a plain `dict` — FastAPI auto-serializes via JSONResponse. Matches `/api/system/stats` pattern.
    6. Use `agent.round_table_state._now_iso` for the snapshot timestamp — existing codebase utility for ISO-8601 UTC.

    **DO NOT:**
    - Add `/orchestrator/agents/status` to `PUBLIC_API_PATHS` in `hermes_cli/dashboard_auth/public_paths.py`. The `test_status_not_in_public_paths` test enforces this.
    - Add caching — the loader already caches internally (`_REGISTRY_CACHE`); endpoint-level caching would introduce staleness.
    - Use `async def` — Pitfall 4.

    Add a brief docstring citing "Phase 67 OBSRV-01/02/03" for traceability. Run the full Phase 67 suite to verify.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → FastAPI handler | Untrusted input crosses here. The endpoint accepts NO query params and NO body — attack surface is minimal. Auth gate (`_require_token`) is the sole protection. |
| FastAPI handler → agent filesystem | Handler reads `~/.hermes/agents/` indirectly via `load_agent_registry_with_warnings`. Filesystem paths are NOT user-controllable (no path input). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-67-01 | Information Disclosure | Unauthenticated caller scrapes agent names + lineage SHAs + missing-expert list | mitigate | Endpoint behind `_require_token(request)` (RESEARCH Pitfall 5); NOT in PUBLIC_API_PATHS. `test_status_requires_auth` + `test_status_not_in_public_paths` enforce the invariant. |
| T-67-01-recon | Spoofing | Attacker uses leaked agent names to craft targeted agent-impersonation attacks | mitigate | Same auth gate as T-67-01. Agent names are operator-only. |
| T-67-01-dos | Denial of Service | Attacker spams the endpoint to amplify registry-loader file I/O | accept | The loader caches in `_REGISTRY_CACHE` (microseconds on cache hit); FastAPI threadpool bounds concurrency; `deque(maxlen=100)` buffer cannot grow. Low-risk — operator is already authenticated. |
| T-67-01-timing | Information Disclosure | Timing side-channel on loader (file count leaks agent inventory size) | accept | Attacker is already authenticated as operator; same info available via `ls ~/.hermes/agents/`. Acceptable per RESEARCH Security Domain table. |
| T-67-01-exception | Denial of Service | Registry exception causes 500 → dashboard crash | mitigate | Try/except around `load_agent_registry_with_warnings`; degrade to `schema_validation_ok=False`. Test `test_registry_failure_graceful` enforces. |
| T-67-01-loop | Denial of Service | Sync handler blocks event loop under heavy traffic | mitigate | Handler is plain `def` — FastAPI runs it in threadpool (RESEARCH Pitfall 4). Does not block other requests. |
