@dataclass(slots=True)
class RoundTableMetricEntry:
    round_id: str
    snapshot_at_iso: str
    duration_ms: float              # total wall time of the captured operation
    token_cost: int                 # from get_last_call_usage()["total_tokens"] (turn) or result["tokensConsumed"] (submit)
    cost_usd: float                 # 0.0 for per-turn; result["costUsdEstimate"] for submit
    turn_count: int                 # 1 for per-turn; len(result["turns"]) for submit
    serial_lock_wait_ms: float      # time spent waiting for acquire_round_or_reject
    early_stop_triggered: bool      # for submit: any event with type=="budget_exceeded"
    status: str                     # "ok" | "completed" | "serial_violation" | "error" | "conflict_409" | ...

def record_round_table_entry(entry: RoundTableMetricEntry) -> None: ...   # thread-safe buffer append
def get_round_table_metrics() -> dict[str, Any]: ...                       # returns {p50_latency_ms, p95_latency_ms, avg_token_cost, total_token_cost, count, status_distribution, serial_lock_wait_p95_ms, early_stop_rate}

@contextmanager
def _turn_capture(round_id: str) -> Iterator[None]: ...   # wraps get_agent_opinion body

@contextmanager
def _submit_capture(round_id: str) -> Iterator[dict]: ... # wraps submit_round_table_result body

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| asyncio task → module-level buffer | Multiple FastMCP asyncio tasks append to `_BUFFER` concurrently. Mitigated by `threading.Lock` inside MetricsBuffer (not `asyncio.Lock` — the buffer is also accessed from sync contexts in OBSRV-03). |
| get_last_call_usage global dict | Process-global `_LAST_CALL_USAGE` overwritten by concurrent LLM calls. INFRA-04 serial lock prevents concurrent LLM calls within one round, but defensive immediate-read after `call_llm` is still required (RESEARCH Pitfall 3). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-67-02-torn | Tampering | Round table buffer torn snapshot under concurrent asyncio tasks | mitigate | `MetricsBuffer.snapshot()` acquires `threading.Lock` (inherited from Wave 0 — T-67-01-thread). |
| T-67-02-tokencost | Information Disclosure | Token cost may leak via unauthenticated endpoint | accept | Token cost is operator-internal; the endpoint (Plan 04) is behind auth gate (T-67-01 in Plan 04). |
| T-67-02-infRA04 | Denial of Service | Instrumentation introduces async dispatch that violates INFRA-04 serial constraint | mitigate | `_turn_capture` and `_submit_capture` are SYNC context managers (`@contextmanager`, not `@asynccontextmanager`). All `perf_counter()` reads are sync. No new `asyncio.create_task`. Verified by inspecting the import: `from contextlib import contextmanager` (NOT asynccontextmanager). |
| T-67-02-exception | Tampering | Exception path skips metrics recording | mitigate | `_turn_capture` / `_submit_capture` use try/finally internally to record on EVERY path including exceptions (test_capture_on_exception proves this). |
</threat_model>
