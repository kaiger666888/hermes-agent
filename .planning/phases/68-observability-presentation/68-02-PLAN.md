# Plan 68-02: Dashboard Panel (`/orchestrator`)

<objective>
Implement the dashboard observability panel at URL `/orchestrator` on the existing `hermes dashboard` FastAPI server. The panel surfaces 3 dimensions (agent registry / round table / memory backend) via client-side `fetch('/orchestrator/agents/status')`. Auth-gated via `_require_token` — NOT in PUBLIC_API_PATHS.

This is OBSRV-05: Dashboard web view — minimal panel surface 3 个维度的实时状态(基于现有 `hermes dashboard` FastAPI server 扩展,不引入新框架)。
</objective>
