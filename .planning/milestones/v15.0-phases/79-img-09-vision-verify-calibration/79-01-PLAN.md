**Calibration functions (D-02, D-07 — stdlib only, no scipy/numpy):**
- `load_metrics_buffer(path: Path) -> list[dict[str, Any]]` — calls `dreamina_stats.read_metrics(path)` to read JSONL. Import: `from plugins.kais_aigc.dreamina_stats import read_metrics` (kais-hermes-skills repo root is on sys.path via conftest bootstrap; for standalone script execution, add repo root to sys.path at top of script: `sys.path.insert(0, str(Path(__file__).resolve().parent.parent.parent.parent.parent))`). If file missing, raise `FileNotFoundError` with clear message (D-10 error handling).
- `compute_confidence_histogram(confidences: list[float]) -> list[int]` — bucket confidences at 0.05 intervals (20 buckets from 0.0-1.0). Returns 20-element list of counts. Each confidence value goes into bucket `min(int(confidence / 0.05), 19)`.
- `_find_bimodal_valley(histogram: list[int]) -> float | None` — D-07 algorithm: find the two highest peaks in the histogram, then find the local minimum between them. The valley is the threshold candidate. If no clear bimodal distribution (single peak dominates, or both peaks are adjacent with no valley between), return `None`. Implementation: (1) find indices of top-2 non-zero buckets, (2) if both are adjacent (|idx1-idx2| <= 1), return None, (3) scan buckets between the two peak indices, find the minimum-count bucket, (4) return `min_bucket_index * 0.05 + 0.025` (midpoint of the valley bucket). If all buckets are zero or only one non-zero bucket, return None.
- `estimate_fp_rate(entries: list[dict], threshold: float) -> float` — D-08 formula: `estimated_fp_rate = (count of entries where success=False AND vision_confidence >= threshold) / (count of entries where vision_confidence >= threshold)`. Returns 0.0 if denominator is 0. Document the assumption clearly: "task failed + high confidence → likely false positive" is a rough proxy, not ground truth.
- `calibrate_stratum(entries: list[dict], stratum_name: str) -> StratumResult` — main per-stratum logic: (1) filter entries to those with `vision_confidence is not None`, (2) if `len(filtered) < MIN_SAMPLE_SIZE`, return StratumResult with `recommended_threshold=None`, `estimated_fp_rate=None`, `rationale=f"Insufficient data: {len(filtered)} entries (need {MIN_SAMPLE_SIZE}). Keeping current 0.7 threshold."`, (3) compute confidence histogram, (4) find bimodal valley, (5) if valley is None, return StratumResult with `recommended_threshold=DEFAULT_THRESHOLD`, `rationale="No clear bimodal distribution detected. Keeping current 0.7 threshold."`, (6) estimate FP rate at the valley threshold, (7) return StratumResult with the valley as recommended_threshold.
- `run_calibration(metrics_path: Path) -> CalibrationReport` — orchestrates: (1) load metrics, (2) for each stratum in CALIBRATION_STRATA, filter entries by `stratum` field + call `calibrate_stratum()`, (3) build CalibrationMetadata, (4) return CalibrationReport.
