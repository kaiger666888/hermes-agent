**Scope guardrail blockquote:**
- Brief intro explaining: CosyVoice zero-shot clone mode requires operator-sourced 3-10s reference wavs per character. This doc provides collection guidelines. The batch validator (`validate_voice_clone_batch.py`) checks technical requirements; operator reviews audio quality manually.

**Section 1: `## Collection Guidelines`**
- **3-10s clean recording:** 3.0s minimum (CosyVoice clone quality floor), 10.0s maximum (avoids excessive file size). Ideal: 5-7s of continuous speech.
- **Content:** Single speaker (the character's voice), natural pace, complete sentences. Avoid pauses > 1s. Avoid laughter/coughing unless character-specific.
- **Environment requirements:**
  - Quiet room (no background music, no TV, no conversation)
  - No echo (avoid empty rooms, hard-surface walls; closets with clothing dampen echo well)
  - Microphone distance: 10-15cm from mouth (too close = plosives/bass boost; too far = room reverb)
  - Avoid wind noise (indoors or use windscreen outdoors)
  - Record in the character's intended emotional tone (neutral/calm for narration; emotional for dramatic characters)
- **Language:** Chinese (matching the target dialogue language). If the character speaks Mandarin, record in Mandarin.

**Section 2: `## File Naming Convention`**
- Canonical path: `assets/<episode>/voice_refs/<character>.wav`
- Examples:
  - `assets/ep-001/voice_refs/alice.wav` — character "alice" in episode "ep-001"
  - `assets/ep-001/voice_refs/narrator.wav` — narrator voice for episode "ep-001"
  - `assets/ep-002/voice_refs/bob.wav` — character "bob" in episode "ep-002"
- Character name = filename stem (e.g. `alice.wav` -> character `alice`)
- Episode = parent directory of `voice_refs/` (e.g. `ep-001` in `assets/ep-001/voice_refs/alice.wav`)
- File extension: `.wav` (lowercase). The validator finds files via `rglob("*.wav")` — case-insensitive on Windows, case-sensitive on Linux.
- Note: the validator is path-agnostic — it validates any `.wav` file found recursively. The convention above is the recommended structure; the validator works even if the operator uses a different layout (e.g. `voice_samples/alice.wav` -> character=alice, episode=null).

**Section 3: `## Technical Requirements`**
- 4 hard rules (matching the batch validator + `validate_voice_clone_ref` contract):
  1. **Duration:** 3.0s <= duration <= 10.0s (computed as `nframes / framerate`)
  2. **Format:** WAV format (RIFF header readable by Python stdlib `wave` module). MP3/FLAC/OGG are NOT accepted even if renamed to `.wav`.
  3. **Sample Rate:** >= 16000 Hz (16kHz minimum for CosyVoice clone quality). 22050Hz, 24000Hz, 44100Hz, 48000Hz are all acceptable.
  4. **Channels:** Mono (1 channel). Stereo files must be downmixed to mono before submission. (Note: validator does NOT convert — operator re-records or converts externally.)
- Each rule has exact thresholds. If any rule is violated, the validator reports it with `rule_id`, `expected`, `actual`, and a human-readable `message`.

**Section 4: `## Troubleshooting`**
- Common issues + solutions:
  - **Too short (< 3s):** Re-record with a longer passage. Read 2-3 sentences instead of 1.
  - **Too long (> 10s):** Trim to a 5-7s segment with the clearest speech. Use `ffmpeg -ss 0 -t 7 -i input.wav -c copy output.wav`.
  - **Stereo instead of mono:** Re-record in mono, or downmix: `ffmpeg -i input.wav -ac 1 output.wav`.
  - **Low sample rate (8kHz/11kHz):** Re-record at >= 16kHz. If the original recording is high quality, resample: `ffmpeg -i input.wav -ar 16000 output.wav`. Note: resampling does NOT add information — if the original was 8kHz, resampling to 16kHz won't improve quality. Re-recording is preferred.
  - **Non-WAV format (MP3 renamed to .wav):** Convert properly: `ffmpeg -i input.mp3 -f wav output.wav`. The `wave` module reads RIFF headers; a renamed MP3 will fail.
  - **Corrupt WAV header:** Re-export from the recording software. Audacity: File > Export > Export as WAV > 16-bit PCM.
  - **Background noise:** Re-record in a quieter environment. If unavoidable, use `ffmpeg -i input.wav -af "afftdn=nr=10" output.wav` for light noise reduction. Heavy noise reduction degrades clone quality.

**WAV validation (D-03 stdlib wave, Claude's Discretion WAV robustness):**
- `validate_wav_file(path: Path) -> CharacterResult` — main per-file validation:
  - Extract character + episode from path
  - Try `with contextlib.closing(wave.open(str(path), "rb")) as wf:` to read `nframes`, `framerate`, `nchannels`

  - Check 4 rules:
    1. **format:** if `wave.open()` raises `wave.Error` -> Violation(rule_id="format", expected="WAV (RIFF)", actual="non-WAV or corrupt", message=f"Not a valid WAV file: {exc}"). Also catch `OSError` and generic `Exception` as format violations.

  - `passed = len(violations) == 0`
  - Return `CharacterResult(character=..., episode=..., path=str(path), passed=passed, duration_s=..., sample_rate_hz=..., channels=..., violations=violations)`
